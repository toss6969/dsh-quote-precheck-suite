# 域判据骨架 —— 化工原料报价预审

> 本文件是 SKILL.md「判据引用」节的落点:判据值域与裁决规则的产品正本。
> 阈值数值与治理态(confirmed)不在本文件——唯一事实源 = 随包 `quote_rules_config.json`。

## 证据优先级(冲突时取高)

1. 可重复的真实执行结果(HIGH)
2. 独立自动化测试结果(MEDIUM;真实执行复核后可升 HIGH)
3. 可复核产物(文件/报告,可被人重新打开验证)(MEDIUM)
4. 明确的外部/平台约束(MEDIUM)
5. 自身声明(LOW——只能定义"声称做什么",不能证明"做到了")

## 域裁决规则

| 结果 | 条件 |
|---|---|
| FAIL | 引擎运行崩溃(步骤失败,无完整报告产出)——修复后重跑,不做部分结论 |
| REVIEW | 任一判据产出 high/medium finding(如 Q11 价差超阈值、Q13 单内不一致、Q14 低于 MOQ、Q15 完整度低于阈值)→ 报告交人工复核 |
| UNCERTAIN | 文件级:无文本层 PDF(扫描件)/编码识别失败/表头识别失败/关键列缺失;判据级:阈值缺失或 confirmed=false、币种或含税口径显式混杂、qty/MOQ 字段缺失 → 转人工清单,不硬判 |
| DONE | 全部报价归一成功且判据链零 finding(机器面无异常) |

## 业务判据链(Q 族 ↔ 登记册条目)

| 判据 | 登记册条目 | 判什么 | 阈值 |
|---|---|---|---|
| Q11 | E-11 多供应商报价异常/横向比较 | 同物料跨供应商 max/min 单价比超阈值 → high;币种/含税口径显式混杂 → 整组 UNKNOWN | 外置(缺省 1.5,可改) |
| Q13 | E-13 报价单一致性 | 同一报价单内同物料单价不一致 → high | 内生(相等性) |
| Q14 | E-14 MOQ/包装数量异常 | 低于 MOQ → high;非整倍 → medium;包装单位混乱 → medium;qty/MOQ 缺 → UNKNOWN | 内生 |
| Q15 | G-16 数据质量面(80-20 核心) | 文件级字段完整度(实填格/应填格)低于阈值 → medium → REVIEW | 外置(缺省 0.8,可改) |

**治理态纪律**:`quote_rules_config.json` 里 threshold 缺失或 confirmed=false 的判据只输出
UNKNOWN 记账,不得硬判(fail-closed)。改口径 = 改配置不改代码。

## 输入归一口径(G-16)

- 表头识别:列头 NFKC 归一后精确匹配内置通用别名库(约 80 条,30 行业方言并集);
  现场方言用 `aliases-config` 外置扩展(只增不减,canonical 必须是规范列之一)。
- 表头识别失败 / 关键列(item、单价)缺失 → 该文件 UNCERTAIN 转人工,不硬猜。
- 数值清洗:币种符号、千分位、全角数字、单位后缀、万元倍率,每步留痕;
  清洗不了的行("面议"、区间价)整行转人工,不静默丢弃。

## 行业口径（化工原料报价预审）

- 化工按吨报价、万元/千分位/全角口径乱:先归一再比价(Q11);
- 吨/公斤/桶 计量口径显式混杂 → UNKNOWN 转人工,不硬判。

## 反模式(出现即判据失效)

- 「用"存在"替代"被验证":文件在 ≠ 功能可用,命令返回 0 ≠ 业务成功」
- 「用 LOW 证据单独支撑关键结论(P0 级)」
- 「为过判定改输入、改预期或放宽判据」
- 「对扫描件/截图/缺失字段硬判——UNCERTAIN 是合法终态,转人工不是失败」
- 「清洗时静默丢弃解析不了的行——必须留痕进台账并转人工」
